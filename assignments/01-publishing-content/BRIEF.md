# Assignment 1 — "Hello Server" (10 points)

Posted Week 2. Due date: see Canvas.

Deliverable: a single `index.html`, published to the school server, with its URL
submitted on Canvas.

## Required content

- Your MSU NetID
- A link to a **GitHub Pages site** — a live `username.github.io` page, NOT a link
  to the repo. The rubric calls this out explicitly and it is worth 2 points.
- Class schedule as a table: **days across the top row, times down the left column**
- 5 courses you've taken, as a list (≥4 accepted)

## Required elements (the assignment names these exactly)

| Element | Contains |
|---|---|
| `<h1>` | your name |
| `<h2>` | your NetID |
| `<a>` | working link to your GitHub Pages site |
| `<h2>` | "Class Schedule" |
| `<table>` | your schedule |
| `<h2>` | "Previous Courses" |
| `<ul>` or `<ol>` | courses you've taken |

## Rubric — 10 points

| Criterion | Pts | Full credit |
|---|---|---|
| Headings | 1 | `<h1>` full name, `<h2>` NetID and section headings, exactly as specified |
| GitHub Pages link | 2 | Points to a **live Pages site**, not a repo, not a broken URL |
| Schedule table | 2 | Well-formed, days across top, times down left |
| Previous courses list | 1 | `<ul>`/`<ol>`, ~5 courses, ≥4 acceptable |
| HTML validation | 2 | Passes https://validator.w3.org/ — warnings fine, errors not |
| Publishing & URL | 2 | Named `index.html`, live at `http://csci331vm.cs.montana.edu/<NetID>/`, link submitted on Canvas |

## Submission

Submit the **working link** on Canvas. Test it first — off campus you must be on
the VPN to reach `student.montana.edu`.

Fallbacks the assignment allows if publishing fails: submit the file to your TA
via Canvas, or last resort, email a zipped HTML file to the TA.

## Pre-submit checklist

- [ ] File is named exactly `index.html`
- [ ] Live at `http://csci331vm.cs.montana.edu/<NetID>/`
- [ ] Opened that URL in a browser and it renders — not just a local file
- [ ] GitHub Pages link clicked and it loads a live page, not a repo
- [ ] Validates clean at https://validator.w3.org/ (use "validate by URI")
- [ ] Table has header cells on both the top row and left column
- [ ] List has at least 4 courses
- [ ] Link submitted on Canvas
