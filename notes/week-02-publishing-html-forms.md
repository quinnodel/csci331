# Week 2 — Publishing, HTML basics, HTML forms

Aug 31 – Sep 4. Assignment attached: **Publishing Content**.

## Publishing (`notes/publishing.html`)

In-class work: publish a basic HTML page with GitHub Pages, then get onto the
course server. Server details are in `../SETUP.md`.

Concepts the notes say you should be able to answer:

- What an IP address is, and what a DNS server does
- What a protocol is, with examples
- How a client and server communicate, in terms of packets
- What a top-level domain is

Reading: MDN "How the Web Works", "Dealing with files", "Web mechanics".

## HTML basics (`notes/HTML_basics.html`)

In-class assignment: an **"About You"** page that uses **headings, bulleted lists,
tables, images, and links** — and validates clean at https://validator.w3.org/.

Concepts to be able to answer:

- Which HTML elements are commonly used
- What the anchor tag does
- How elements nest hierarchically
- What an attribute is, its syntax, and examples
- How to validate an HTML document

Reading: W3Schools HTML Elements + HTML Attributes; MDN "Getting started with
HTML" and "HTML table basics".

## HTML forms (`notes/HTML_forms.html`)

In-class work: build a page with a variety of input types and submit it to a form
viewer to see what actually gets sent.

Concepts to be able to answer:

- What the form's `action` attribute is for
- The difference between `for`, `type`, `id`, `name`, and `value`
- GET vs POST, and when you'd use each

Reading: W3Schools HTML Forms through the Input Attributes section; MDN's `<input>`
element docs. The notes suggest comparing how form widgets render across browsers.
